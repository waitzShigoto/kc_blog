# 模組化 CSS 架構

本專案已從單一的 `globals.css` 重構為模組化的 CSS 架構，提高了可維護性和組織性。

## 文件結構

```
src/styles/
├── index.css        # 主要導入文件
├── variables.css    # CSS 變數和顏色定義
├── base.css         # 基礎樣式和實用工具
├── tags.css         # 標籤和分類顏色
├── code.css         # 代碼相關樣式
├── prose.css        # 文章內容樣式
└── README.md        # 本文件
```

## 模組說明

### 1. `index.css` - 主要導入文件
統一導入所有模組化的 CSS 文件，確保正確的載入順序。

### 2. `variables.css` - CSS 變數
- 明亮模式和暗黑模式的顏色變數
- 標籤配色系統
- 主要的設計 token

### 3. `base.css` - 基礎樣式
- HTML 基礎元素樣式（body, html）
- Tailwind 類別覆蓋
- 實用工具類（line-clamp, hover 效果等）
- 動畫定義
- 捲軸樣式
- 進度條樣式

### 4. `tags.css` - 標籤和分類
- 標籤顏色類別（.tag-*）
- 分類顏色類別（.category-*）
- 暗黑模式適配

### 5. `code.css` - 代碼樣式
- 內聯代碼樣式
- 代碼區塊樣式
- 語法高亮適配
- 暗黑模式代碼樣式

### 6. `prose.css` - 文章內容
- 標題樣式（h1-h6）
- 段落和文字樣式
- 連結樣式和特效
- 引用區塊
- 列表樣式
- 表格樣式
- 圖片樣式和特效
- 特殊內容區塊（callout, kbd, math 等）
- Jekyll 遺留樣式的現代化替代

## 使用方式

主要的 `globals.css` 現在只需要導入 Tailwind 和模組化架構：

```css
@import "tailwindcss";
@import '../styles/index.css';
```

## 維護指南

### 添加新樣式
1. 確定樣式屬於哪個模組
2. 在對應的 CSS 文件中添加樣式
3. 如果需要新的模組，創建新文件並在 `index.css` 中導入

### 修改現有樣式
1. 找到對應的模組文件
2. 直接修改相關樣式
3. 測試明亮和暗黑模式

### 顏色變數
所有顏色都使用 CSS 變數定義，修改顏色請在 `variables.css` 中進行。

## 優勢

1. **模組化**：每個文件專注於特定功能
2. **可維護性**：易於找到和修改特定樣式
3. **重用性**：樣式可以在不同組件間重用
4. **組織性**：清晰的文件結構和命名規範
5. **效能**：通過 `index.css` 統一管理載入順序

## 注意事項

- 所有模組都通過 `index.css` 導入，不要直接導入個別模組
- 保持 CSS 變數的一致性
- 新增樣式時考慮明亮/暗黑模式適配
- 遵循現有的命名規範
