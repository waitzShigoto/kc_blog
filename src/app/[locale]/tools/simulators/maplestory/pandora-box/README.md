# 潘朵拉箱子模擬器 (Pandora Box Simulator)

## 功能特色

### 核心功能
- **潘朵拉箱子開啟**: 每次開啟潘朵拉箱隨機獲得一個獎勵
- **批量使用**: 支援一次使用 10 個或 100 個潘朵拉箱子
- **大獎選單與自動抽獎**: 支援設定目標大獎（如永恆套裝、頂級培羅德飾品等）並自動抽到為止
- **即時統計**: 追蹤所有已獲得獎勵的數量與實際機率
- **歷史記錄**: 顯示最近 100 次抽獎的歷史結果

### 獎勵與潛能系統
包含 **147 種不同獎勵**，且部分裝備附帶潛在能力判定：
- **傳說級潛能 (Legendary)**: 包含航海師武器、神秘冥界幽靈武器與防具、頂級培羅德飾品等。
- **稀有級潛能 (Rare)**: 包含永恆上衣、褲子、帽子、肩膀、披風、手套及鞋子等選擇箱子。
