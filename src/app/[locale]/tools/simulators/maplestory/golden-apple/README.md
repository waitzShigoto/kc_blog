# 黃金蘋果模擬器 (Golden Apple Simulator)

## 功能特色

### 核心功能
- **黃金蘋果抽獎**: 每次使用黃金蘋果隨機獲得一個獎勵
- **碎片收集系統**: 每使用一次黃金蘋果獲得一個碎片
- **批量使用**: 支援一次使用 10 個或 100 個黃金蘋果
- **即時統計**: 追蹤所有獎勵的獲得次數和實際機率

### 獎勵系統
共有 **86 種不同獎勵**，包括：

#### 超稀有獎勵 (≤0.5%)
- 武公的靈魂寶珠 (0.50%)
- 彩虹月石寶石圖騰 (0.10%)
- 各色寶石圖騰 (0.35%)

#### 稀有獎勵 (0.5%-1.0%)
- 神祕冥界變換箱 (0.30%)
- 各種心臟道具 (0.40%)
- 星力強化券 (0.40%)
- 內襯交換券 (0.60%)
- 各種祕藥 (0.70%)

#### 普通獎勵 (1.0%-2.0%)
- 各種水滴石 (1.20%)
- 各種裝備 (1.25%)
- 靈魂寶珠 (1.50%)

#### 常見獎勵 (>2.0%)
- 漆黑的BOSS飾品碎片 (3.00%)
- 經驗值券 (2.50%-4.00%)
- 航海師選擇箱 (2.60%-4.40%)
- 核心寶石交換券 (5.00%)
- 暗黑輪迴星火 (6.00%)

### 統計功能
- **使用統計**: 已使用黃金蘋果總數
- **碎片追蹤**: 當前碎片數量與進度條
- **獎勵分佈**: 
  - 顯示每種獎勵的獲得次數
  - 計算實際獲得機率
  - 與官方機率對比
- **歷史記錄**: 最近 100 次抽獎記錄
- **機率查詢**: 完整的 86 種獎勵機率表

### 視覺特色
- **稀有度顏色標示**:
  - 紅色: 超稀有 (≤0.5%)
  - 橙色: 稀有 (0.5%-1.0%)
  - 紫色: 罕見 (1.0%-2.0%)
  - 藍色: 普通 (2.0%-4.0%)
  - 灰色: 常見 (>4.0%)

## 技術實現

### 數據結構
- `data.ts`: 包含所有 86 種獎勵及其機率
- `GoldenAppleClient.tsx`: 主要客戶端組件
- `page.tsx`: Next.js 頁面組件

### 核心邏輯
1. **權重隨機**: 根據機率權重隨機選擇獎勵
2. **碎片累積**: 自動追蹤碎片數量（每次 +1）
3. **統計追蹤**: 即時更新各項統計數據
4. **機率計算**: 計算實際獲得機率並與官方機率對比

### 狀態管理
使用 React Hooks 管理：
- `useState`: 管理 UI 狀態
- `useRef`: 追蹤累積數據
- `useCallback`: 優化性能
- `useEffect`: 處理副作用

## 使用方式

1. 點擊「使用黃金蘋果」按鈕
2. 查看獲得的獎勵
3. 觀察碎片累積進度
4. 使用批量功能快速抽獎
5. 查看統計數據和歷史記錄
6. 在機率表中查詢各獎勵機率

## 路徑

- 開發環境: `http://localhost:3001/zh/tools/simulators/maplestory/golden-apple`
- 生產環境: `{siteUrl}/zh/tools/simulators/maplestory/golden-apple`

## 機率說明

### 總機率驗證
所有獎勵機率總和為 100%，確保每次抽獎必定獲得一個獎勵。

### 稀有度分佈
- 超稀有 (≤0.5%): 約 2.5% 總機率
- 稀有 (0.5%-1.0%): 約 15% 總機率
- 罕見 (1.0%-2.0%): 約 30% 總機率
- 普通 (2.0%-4.0%): 約 20% 總機率
- 常見 (>4.0%): 約 32.5% 總機率

## 注意事項

- 此模擬器僅供娛樂，實際遊戲機率可能略有差異
- 所有機率數據基於提供的官方資料
- 統計數據會在重置時清空
- 歷史記錄最多保留 100 筆
- 實際機率會隨著抽獎次數增加而趨近於理論機率
