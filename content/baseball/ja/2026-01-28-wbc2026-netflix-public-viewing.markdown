## 2026 WBC Netflix 独占配信について

2026年ワールド・ベースボール・クラシック（WBC）は、日本国内ではNetflixが独占配信権を取得しました。地上波テレビでの生中継は行われません。

### 配信概要

| 項目 | 内容 |
|------|------|
| **配信元** | Netflix |
| **配信形式** | ライブ配信 + オンデマンド |
| **対象試合** | 全47試合 |
| **地上波放送** | なし |
| **他配信サービス** | なし（Amazon Prime Video、DAZNなども配信なし） |

---

## ホームタウンヒーロー・パブリックビューイング

Netflixは「2026 ワールドベースボールクラシック ホームタウンヒーロー・パブリックビューイング」を開催します。

### 開催概要

| 項目 | 内容 |
|------|------|
| **会場数** | 全国30箇所 |
| **入場料** | 無料 |
| **主催** | 選手の出身自治体・出身校 |
| **共催** | Netflix |

### 対象試合

- 東京プール 日本代表戦4試合
- 準々決勝（日本が進出した場合）
- 準決勝（日本が進出した場合）
- 決勝（日本が進出した場合）

### 開催条件

1. 侍ジャパン選手の出身地またはゆかりのある地域であること
2. 自治体または出身校が主催者となること
3. Netflixとの共催契約を締結すること
4. 入場料・チケット販売は禁止（無料開催のみ）

### 会場一覧

開催地の詳細は決定次第、公式発表される予定です。30人の選手それぞれの出身地で開催されるため、以下のような地域が候補となります：

- 大谷翔平：岩手県奥州市
- 山本由伸：岡山県備前市
- 村上宗隆：熊本県熊本市
- 佐藤輝明：兵庫県西宮市
- その他選手の出身地

## 一般店舗でのパブリックビューイング

### 現時点での方針

Netflixは一般店舗（スポーツバー、飲食店など）でのパブリックビューイングについて「丁寧に精査しながら進める」としています。

### 注意事項

- 一般店舗での無断上映は著作権侵害となる可能性あり
- 商業施設での上映には別途許諾が必要
- 詳細な条件は今後発表予定

## 中継制作体制

| 試合 | 制作担当 |
|------|----------|
| **日本の試合** | 日本テレビ |
| **海外の試合** | J SPORTS |

Netflixは日本テレビ、J SPORTSと連携して中継を制作します。ただし、地上波での無料放送は行われません。

## まとめ

2026年WBCを映像でリアルタイム視聴するには：

1. **Netflix加入** - 最も確実な方法
2. **ホームタウンヒーロー・パブリックビューイング** - 選手出身地で無料開催
3. **ラジオ** - ニッポン放送で全試合生中継

一般的なパブリックビューイングや地上波放送は現時点では予定されていません。
