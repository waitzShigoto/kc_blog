## 2026 WBC Netflix 獨家轉播

2026年世界棒球經典賽（WBC）在日本由Netflix取得獨家轉播權，不會有電視直播。

### 轉播概要

| 項目 | 內容 |
|------|------|
| **轉播平台** | Netflix |
| **轉播形式** | 直播 + 隨選回看 |
| **轉播場次** | 全部47場 |
| **電視轉播** | 無 |
| **其他串流平台** | 無（Amazon Prime Video、DAZN等皆無） |

---

## Hometown Hero 公開播映

Netflix將舉辦「2026 World Baseball Classic Hometown Hero Public Viewing」活動。

### 活動概要

| 項目 | 內容 |
|------|------|
| **會場數** | 全日本30處 |
| **入場費** | 免費 |
| **主辦** | 選手出身地方政府・母校 |
| **協辦** | Netflix |

### 適用賽事

- 東京分組賽 日本隊4場比賽
- 八強賽（日本晉級時）
- 四強賽（日本晉級時）
- 冠軍戰（日本晉級時）

### 舉辦條件

1. 必須是侍ジャパン選手的出身地或相關地區
2. 地方政府或母校必須擔任主辦單位
3. 需與Netflix簽訂協辦合約
4. 禁止收取入場費或販售門票（僅限免費舉辦）

### 會場一覽

詳細舉辦地點將於確定後由官方公布。由於是以30名選手各自的出身地舉辦，以下地區為可能候選：

- 大谷翔平：岩手縣奧州市
- 山本由伸：岡山縣備前市
- 村上宗隆：熊本縣熊本市
- 佐藤輝明：兵庫縣西宮市
- 其他選手出身地

## 一般店家的公開播映

### 目前方針

Netflix對於一般店家（運動酒吧、餐廳等）的公開播映表示「將謹慎評估後進行」。

### 注意事項

- 一般店家未經授權播映可能構成著作權侵害
- 商業設施播映需另行取得許可
- 詳細條件將於日後公布
